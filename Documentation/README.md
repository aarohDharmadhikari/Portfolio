
# Aaroh Dharmadhikari — Personal Portfolio

**AI-Powered Developer · Pune, India**

My personal portfolio website, built to present my technical background, selected projects, skills, education, certifications, and professional journey.

[**View Live Portfolio**](https://portfolio-xi-ivory-f5wgx7e77w.vercel.app/)

---

## Overview

This project represents my professional identity through a modern, responsive website. It brings together my development work and interests in software engineering, artificial intelligence, and web technologies.

The design direction emphasizes clarity, a dark visual foundation, emerald accents, thoughtful typography, and restrained animation.

## Core Areas

- **About:** Professional background and interests.
- **Skills:** Technical capabilities and tools.
- **Projects:** Individual and collaborative development work.
- **Experience:** Verified professional and project-based experience.
- **Education:** Academic background and qualifications.
- **Contact:** Professional links and contact information.
- **Services:** A dedicated page reserved for future service information.

Feature availability and project statuses must reflect the current implementation.

## Technology Stack

| Technology | Purpose |
|---|---|
| Next.js | Application framework and routing |
| React | User interface |
| TypeScript | Type safety |
| Tailwind CSS | Styling and responsive layouts |
| Framer Motion | Animations and transitions |
| Lucide React | Interface icons |
| Three.js | Visual effects where retained |

The exact stack may evolve as the website is redesigned.

## Development

Requirements: Node.js and npm versions compatible with the project's Next.js version.

```bash
npm install
npm run dev
```

Other project scripts:

```bash
npm run lint
npm run build
npm run start
```

Available scripts are defined in `../package.json`. Run the relevant checks before deploying changes.

## Engineering Principles

- Maintain a clear and consistent user experience.
- Keep components and content maintainable.
- Prioritize responsive design and accessibility.
- Respect reduced-motion preferences.
- Keep project descriptions and credentials accurate.
- Distinguish personal projects from collaborative contributions.
- Keep technical documentation aligned with the implementation.
